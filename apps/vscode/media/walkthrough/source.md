# Open the source to the side

**Open Source to the Side** in the editor title of the diagram opens the JSON next to it, and
**Open Diagram to the Side** in the title of the text editor does the reverse.

Every change on the canvas is one edit of the file, so Cmd/Ctrl+Z undoes it in either editor.
While the text is not a valid diagram, the canvas keeps the last valid state, read-only, and the
Problems view says what to fix.
