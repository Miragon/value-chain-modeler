# Value Chain Modeler has moved

> [!IMPORTANT]
> This repository is archived and read-only. The Value Chain Modeler now lives in the
> [Miragon modeler suite](https://github.com/Miragon/modeler-suite), in
> [`modelers/value-chain`](https://github.com/Miragon/modeler-suite/tree/main/modelers/value-chain), with its full git history.

Nothing changes for users:

- **npm packages** keep their names and version lines; new releases come from the suite: [`@miragon/value-chain-schema-model`](https://www.npmjs.com/package/@miragon/value-chain-schema-model), [`@miragon/value-chain-renderer`](https://www.npmjs.com/package/@miragon/value-chain-renderer).
- **VS Code extension** `miragon-gmbh.value-chain-modeler` stays the same ([Marketplace](https://marketplace.visualstudio.com/items?itemName=miragon-gmbh.value-chain-modeler)).

**Issues and pull requests** go to [Miragon/modeler-suite](https://github.com/Miragon/modeler-suite/issues); the open issues of
this repository were moved there. Development, CI and releases are described in the suite's
[README](https://github.com/Miragon/modeler-suite#readme) and [CONTRIBUTING.md](https://github.com/Miragon/modeler-suite/blob/main/CONTRIBUTING.md), the
modeler itself in [`modelers/value-chain/README.md`](https://github.com/Miragon/modeler-suite/blob/main/modelers/value-chain/README.md).
